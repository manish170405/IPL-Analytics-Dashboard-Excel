IPL Data Analysis & Excel Dashboard

 Project Overview

This project is an IPL Data Analysis and Interactive Dashboard created using Microsoft Excel.

The objective of this project is to analyze IPL match data and extract meaningful insights related to team performance, player performance, venues, and seasons. The project includes data cleaning, data analysis using Pivot Tables, and data visualization using charts and slicers.

 Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Excel Formulas
* Data Cleaning
* Data Analysis
* Data Visualization

 Dataset

The project uses IPL match and ball-by-ball delivery data.

 Dataset Files

* `matches.csv` – Contains match-level information such as season, teams, venue, winner, and match result.
* `deliveries.csv` – Contains ball-by-ball information including batsmen, bowlers, runs, wickets, and deliveries.

 Data Cleaning

The raw data was cleaned and prepared before analysis.

The cleaning process included:

* Removing duplicate records
* Handling missing values
* Standardizing team names
* Checking inconsistent values
* Preparing the data for analysis

 Analysis Performed

 Team Performance

* Number of matches played
* Team-wise wins
* Team win distribution
* Comparison of team performances

 Batting Performance

* Top run scorers
* Player-wise run analysis
* Identification of high-performing batsmen

 Bowling Performance

* Top wicket takers
* Player-wise wicket analysis
* Identification of leading bowlers

 Venue Analysis

* Matches played at different venues
* Most frequently used venues
* Venue-wise match distribution

 Season Analysis

* Number of matches played in each season
* Season-wise comparison
* Match distribution across seasons
